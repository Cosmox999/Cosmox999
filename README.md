## Featured Projects

### Multi-Agent GenAI Research Assistant
> Autonomous 5-agent pipeline — Planner → Researcher → Analyst → Critic → Reporter — built with LangGraph, Groq (Llama-3.1-8B), and Tavily Search. Implements an LLM-as-judge critique loop with automated revision. Runs end-to-end in ~25 seconds on free-tier APIs.

`LangGraph` `Groq` `Tavily` `Python`
&nbsp;→ [Repository](https://github.com/Cosmox999/Cosmox999-Multi-Agent-Research-Assistant-23B1514)

### Waste Container Detection — YOLOv8
> Trains YOLOv8n on the Open Images waste container class from scratch. Full pipeline: YAML dataset config → 50-epoch training → evaluation → real-time video inference at conf=0.5. Achieves mAP@0.5 = 0.73.

`YOLOv8` `PyTorch` `OpenCV` `Computer Vision`
&nbsp;→ [Repository](https://github.com/Cosmox999/waste-container-detection-yolov8)

### PPO Self-Driving Car — Reinforcement Learning
> PPO agent trained in Gymnasium highway-v0 using Stable-Baselines3. Reaches mean episode reward of 20.7 with zero crashes across 10,240 training timesteps. Includes reward curve plot and MoviePy evaluation video.

`PPO` `Stable-Baselines3` `Gymnasium` `PyTorch`
&nbsp;→ [Repository](https://github.com/Cosmox999/ppo-self-driving-car-rl)

### GPT-2 Fine-Tuning — Next Word Prediction
> Fine-tunes GPT-2 on WikiText-2 using the Hugging Face Trainer API with causal language modelling. Implements a custom top-k accuracy metric from scratch. Achieves perplexity of 27.17 and Top-3 accuracy of 56.97%.

`GPT-2` `Hugging Face` `Transformers` `NLP` `PyTorch`
&nbsp;→ [Repository](https://github.com/Cosmox999/gpt2-next-word-prediction)

### Credit Card Analysis — Fraud Detection & Segmentation
> Part 1: Isolation Forest flags 490 anomalies in 284K transactions. Part 2: k-means implemented from scratch in NumPy (elbow method → k=3), followed by LinearRegression predicting credit limits (R² = 0.76).

`Isolation Forest` `K-Means` `NumPy` `scikit-learn` `Python`
&nbsp;→ [Repository](https://github.com/Cosmox999/Credit-card)
